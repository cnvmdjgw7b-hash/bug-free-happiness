永護寧｜照管批次連接器 v4.3

本版直接更新 v4.2，不重做既有批次讀取核心。
修正重點：登入後停在 csms.mohw.gov.tw 的入口首頁，也能直接開始抓取，不再把「必須先手動進 100－個案總查詢」當成前置條件。

v4.3 查詢順序：
1. 先用目前登入中的官方 Session，直接呼叫 CS100 的官方查詢端點 /lcms/ca/filter。
2. 以身分證查到唯一 1 筆官方資料後，驗證 ca100id。
3. 直接讀最新照顧計畫、指定月份服務紀錄、個人額度。
4. 只有入口直查失敗時，才啟用 UI 備援：自動找「失能者個案管理」→「100－個案總查詢」→身分證欄位。

本版另外補強：
- 入口卡片與選單的點擊元素偵測：支援 a / button / onclick / role=button / data-href / data-url / routerlink。
- 若 100 頁連結有可辨識網址，優先在同一分頁開啟，避免另開分頁造成 sessionStorage 續跑遺失。
- page_hook.js / page_bridge.js 改為載入完成後再移除注入標籤，降低入口頁 document_start 時注入失敗。
- 保留 v4.2 的跨頁暫存與自動續跑，作為備援。

仍保留：
- 一次貼上或匯入 TXT / CSV 多筆身分證
- 官方 CS100 唯一 1 筆驗證
- ca100id 驗證
- 最新照顧計畫
- 指定月份服務紀錄
- 個人額度
- 單案失敗不中斷
- CSV / JSON 匯出

操作：
1. 停用／移除舊版，只留 v4.3。
2. 正常登入 https://csms.mohw.gov.tw/。
3. 登入後停在你截圖的「功能快速入口」首頁即可，不要先進 100。
4. 點 🐝，貼入／匯入批次清單，選月份。
5. 按「開始批次讀取」。
6. 正常情況會先顯示「入口頁直接查詢官方 CS100…」，成功後直接進入照顧計畫／服務紀錄／額度讀取。

隱私：
- 身分證不做長期保存。
- 只有 UI 備援必須跨頁時，才暫存在該瀏覽分頁的 sessionStorage。
- 批次完成或停止即清除。
- 不自動登入、不修改官方資料、不送異動通報。

離線驗證：
- content.js / page_bridge.js / page_hook.js 已通過 JavaScript 語法檢查。
- 已用模擬官方 /lcms/ca/filter + showCaseDetail 回應測試「入口頁直接 FIND_CASE」流程，可由入口情境取得 ca100id。
- 真實照管站的登入 Session 與角色權限只能在你的已登入瀏覽器內做最後實機驗證。
